## Deploy

Copy these files over the existing `niwdy.github.io` repository, then run:

```powershell
git status
git add .
git commit -m "Launch V3 brand and Engineering Notes No. 2"
git pull --rebase origin main
git push origin main
```

If the rebase reports a conflict, resolve it before pushing. Do not force-push.

No npm/build step is required.
